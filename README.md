# LCD
Data about villages in northern Estonia ca AD 1220, recorded in the Liber Census Daniae.

This is a spatial dataset (ESRI shapefile) constructed from the Great List of Estonia, part of the Danish Census Book (Liber Census Daniae, hereafter LCD), a 13th century tax registry containing information about villages in Northern Estonia. The dataset consists of 494 settlements with their respective historical and later names, number of unci (ploughlands, i.e. an ancient taxation unit), ID number, point locations and affiliation to territorial units (province, kylaegund, parocchia).
The locations of villages in the modern landscape were identified using Johansen’s (1933) work and digitised historical maps provided as a WMS-service by the Estonian Land Board.
The dataset was created by Kristo Siig in 2020 as part of my PhD dissertation work on locational aspects of Iron Age forts in northern Estonia. It was updated in 2026.

Sources:
JOHANSEN 1933: P. JOHANSEN, Die Estlandliste des Liber Census Daniae (Kopenhagen / Reval 1933).
