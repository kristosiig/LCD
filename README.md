# LCD
Data about settlements in northern Estonia ca AD 1220, recorded in the Liber Census Daniae.

This is a spatial dataset (CSV and XLSX tables with point coordinates in EPSG:3301, i.e. L-EST97) constructed from the Great List of Estonia, part of the Danish Census Book (Liber Census Daniae, hereafter LCD), a 13th century tax registry containing information about settlements in Northern Estonia. The dataset consists of 494 settlements with their respective historical and later names, number of unci (ploughlands, i.e. an ancient taxation unit), ID number, point locations and affiliation to territorial units (province, kylaegund, parocchia).
The locations of settlements in the modern landscape were identified using Johansen’s (1933) work and digitised historical maps provided as a WMS-service by the Estonian Land Board.
The dataset was created by Kristo Siig in 2020 as part of my PhD dissertation work on locational aspects of Iron Age forts in northern Estonia. 

Version history:
V1 included only the list of settlements with ploughlands.
V3 (2026 update) added information about territorial affiliation (_kylaegund, parocchia_, province__) and minor additions of settlement names without ploughlands and minor revisions of metadata.

Sources:
